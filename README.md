# Промпт к исследованию синтетических респондентов

Этот репозиторий содержит только два файла: двухэтапный промпт в [`PROMPT.md`](PROMPT.md) и настоящую инструкцию. Код для запуска не нужен.

Промпт предназначен для моделирования ответов на вопрос об узнаваемости 13 торговых сетей среди 77 вымышленных жителей Москвы и Санкт-Петербурга: 42 человека 20–34 лет и 35 человек 50–65 лет. Один профиль сначала создаётся и фиксируется, затем **тот же самый** синтетический респондент отвечает по всем 13 сетям. Результат — таблица CSV: 77 строк данных, по 17 полей в каждой (4 демографических поля и 13 ответов). Всего — 1001 ответ о сетях; это не ответы реальных людей.

## Как использовать

1. В `PROMPT.md` указана дата реального опроса — **15 октября 2026 года**. Для другого исследования замените её фактической датой.
2. Отправьте текст **части 1** в новый чат. Проверьте, что получены 77 профилей с ID 1–77, возрастами, городами и полом из списка. Сохраните полный ответ модели без изменений.
3. В **том же чате**, где остались зафиксированные профили, отправьте текст **части 2**. Сохраните исходный ответ с 77 строками. Если система обрывает ответ, запросите только недостающие строки и задокументируйте продолжение.
4. Для анализа отдельно сопоставьте ответы с реальным опросом. Не передавайте модели человеческие частоты до завершения генерации и не исправляйте синтетические ответы ради лучшего совпадения.

Для документирования нового запуска запишите дату, название и доступный технический идентификатор модели, параметры генерации (только если они фактически установлены), оба отправленных текста, исходные профили и исходные ответы. Вывод одной модели может отличаться при повторном запуске.

## Связь со статьёй

Промпт сопровождает статью «Синтетические респонденты на основе больших языковых моделей в маркетинговых исследованиях». В анализе рассматриваются 13 торговых сетей и две возрастные группы: 42 респондента 20–34 лет и 35 респондентов 50–65 лет. **Это восстановленная формулировка**, а не архив дословных исторических сообщений, которыми получены приведённые в статье 77 анкет. Полные тексты исходных запросов и сгенерированных профилей в этих двух файлах отсутствуют. Поэтому новая генерация по `PROMPT.md` не является точным воспроизведением исходного запуска и не обязана совпасть с опубликованными числами. Для точного архива исследования следует заменить текст на скопированные без изменений исходные запросы и приложить зафиксированные профили из того чата.

Синтетические респонденты позволяют проверить исследовательские гипотезы, но сам по себе такой промпт не доказывает, что модель копирует конкретного человека или заменяет опрос реальных покупателей.
